# PS1XP v0.1.0-rc.4

- Convert has a centered file drop area, a Choose file button, a drag-over highlight, and a loaded-disc row.
- Open a ZIP containing one BIN or ISO, or one CUE and its referenced tracks. The app uses a temporary folder to stage only the needed files and removes them when the disc is cleared, replaced, or the app closes normally.
- The Artwork page can load a custom 720 × 504 PSP preview frame.
- The portable package still includes the patched conversion engine, runtime, and resources. It is unsigned.

ZIP selection, nested tracks, malformed ZIP rejection, and a multi-track ZIP conversion were tested in the build environment. Windows Explorer drag-over behavior and PSP playback from this exact package still need testing.
